# nodevel-app

A [Nodevel](https://github.com/mobinpo/nodeframework) application — the Laravel-inspired web framework for Node.js.

## Getting Started

```shell
npm run dev
```

Open [http://localhost:8000](http://localhost:8000) in your browser.

## Artisan

```shell
npm run artisan            # list all commands
npm run artisan route:list
npm run artisan migrate
npm run test
```
